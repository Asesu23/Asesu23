## Featured projects

**[Slideshow Publisher](https://github.com/Asesu23/TikTok-Slideshow-Publisher)**
Full-stack app that turns a set of photos into a TikTok-ready video and publishes it straight to TikTok via the Content Posting API — OAuth login, `ffmpeg` rendering with crossfades and text overlays, live preview, chunked upload.
`Node.js` `Express` `TypeScript` `React` `Vite` `Tailwind` `Docker Compose` `Caddy` `ffmpeg` `WireGuard`

**[Mimo Profile Widget](https://github.com/Asesu23/mimo-profile-widget)**
A live SVG badge that pulls Mimo streak/coins/XP into a GitHub README — the same one running above. Reverse-engineered an undocumented API, built on Feature-Sliced Design, with tokens encrypted at rest (AES-256-GCM) and cached responses for instant loads.
`Next.js 14` `TypeScript` `Upstash Redis` `Firebase Auth` `Feature-Sliced Design`

**[AutoCAD Plugin Setup](https://github.com/Asesu23/AutoCADPluginSetup)**
Distributable installer for a custom AutoCAD plugin.

**myPortfolio** — *in progress, coming soon.*
